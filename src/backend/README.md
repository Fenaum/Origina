# Origina LOS - Backend

## Overview
Origina LOS is a modern loan origination system designed for Non-QM lending.
It includes:
- FastAPI backend
- PostgreSQL database
- JWT auth + RBAC
- Document management system (S3)
- Automated workflow + eligibility logic
- Clean architecture (API, Services, Repositories, Models, Schemas)

## Tech Stack
- Python 3.11+
- FastAPI
- SQLAlchemy + Alembic
- PostgreSQL
- JWT Authentication
- S3 Document Storage
